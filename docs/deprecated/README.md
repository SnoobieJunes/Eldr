# docs/deprecated — retired documents

Everything in this folder is **historical**: superseded planning artifacts, one-time
audits/reviews whose findings were acted on, and dated research notes. Kept for the
record (several are cited by DEVIATIONS entries and commit messages), but **nothing in
here describes the current system — do not build from these.**

The live documentation set is the flat `docs/` folder one level up. If a document in
here contradicts one out there, the one out there wins.

Rule for adding to this folder: a doc moves here when it is superseded by shipped code,
by a newer doc, or by a DEVIATIONS entry — it is never edited to "catch it up."
